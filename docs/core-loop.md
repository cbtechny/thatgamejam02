# 当前核心循环

更新：2026-11-06。以 [当前方案](game-design.md) 为准，旧版已归档。

进入音乐盒舞台 → 观察目标与机关 → 转柄调整碎片或环境 → 释放／启动风扇 → 观察结果并继续操作 → 失败后快速重试 → 送达目标 → 成功演出 → 下一舞台。

## 第一关

按阶段提示学习转柄、释放与接取；完成三片收集、拼合和入锁。成功后进入第二关，不能继续使用整款游戏已结束的文案。

## 第二关

观察浮木、低岩石和高处目标。调水位使前方合适的平台可达，再用风扇逐段送出碎片。没有可达目标时继续调整；困在岩石时重置。抵达目标后进入第三关。

## 第三关

保持海洋移动规则，转柄同时移动照明。观察更长的路线，经过三根浮木、避开两处岩石，到达高处目标。关键落点仍应可辨认，不能要求盲试。成功后进入终场。

## 恢复与结束

暂停提供继续、重试、返回标题。重试清除输入、计时、移动、音效与演出残留。终场展示音乐盒完成状态及制作名单，支持返回标题或从第一关重新开始。

这些是待完成的统一体验，不代表所有流程已经接入。任务与验收见 [完成计划](completion-plan.md)。
