CLOCKS IN ORANGE
A music-box puzzle in three movements — thatgamejam #02

WINDOWS
Extract the entire ZIP, then run ClocksInOrange.exe.
Keep ClocksInOrange.pck beside the executable. Godot is not required.

CONTROLS
Mouse: drag the crank. Space: release the key / fire the ocean fan.
Level 1: time the release so the key meets the moving piece. Joining is automatic.
Levels 2 and 3: change the tide, then hop to the first reachable platform ahead.
A rock is a dead end. Press R in ocean levels, or use Retry in the pause menu.
Esc: pause/resume. Tab/arrows and Enter: navigate menus.
Mute affects all game audio and stays set across stages during this run.
Use Exit game or close the window to quit.
