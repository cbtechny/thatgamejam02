# Winder Test 1: Time Scroll

Run the project with **F5**, or open `winder_test_1_time_scroll.tscn` and run it with **F6**.

- Hold the left mouse button on the winder and drag clockwise to add progress.
- Drag counterclockwise to reduce progress.
- Release to play the corresponding final portion of the forward track while progress drains.
- At zero, both tracks are silent until the next wind.

The scene and its scripts and test-only media live in this folder. The cabinet artwork is shared from `res://Art/Textures/`.
